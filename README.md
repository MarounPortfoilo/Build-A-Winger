# ⚽ Build-A-Winger

**Build-A-Winger** is a football-based web project inspired by games like FIFA/EA FC. The idea is to let users create their own winger by selecting players and clubs and then generate a set of attributes for the final player.

This project is **still a work in progress**, and I’m continuing to add features, improve the design and fix things as I develop it.

## 🎮 What is it?

The main idea is simple: **build your own winger**.

The project takes football players and their attributes and uses them to create a final winger with stats such as:

* ⚡ Pace
* 🎯 Shooting
* 🅰️ Passing
* 🕺 Dribbling
* 🛡️ Defending
* 💪 Physical

The player's overall rating is then calculated from these attributes to give the finished winger a FIFA-style rating.
